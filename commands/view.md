# Страница журнала

Аргумент команды (может быть пустым): `$ARGUMENTS`

1. Папка: аргумент, если он задан; иначе — папка проекта этой сессии `${CLAUDE_PROJECT_DIR}` (если
   это выражение не заменилось путём — твоя основная рабочая папка). Относительный путь считай от
   папки проекта и передавай абсолютный.
2. Вызови инструмент `journal_open` с `cwd` = эта папка. Папку передавай всегда: без неё сервер может
   взять не тот проект.
3. Инструмент строит страницу и открывает её браузером по умолчанию; в ответе — путь к файлу
   (`page`). Назови человеку этот путь: если браузер не открылся (удалённая машина, нет графической
   среды), страницу можно открыть вручную.
4. «No journal for …» или «The journal has not been built yet» — папка не подключена или журнал
   ещё собирается: предложи `/agent-logbook:connect` или проверить готовность через
   `/agent-logbook:status`.
   Инструмента `journal_open` нет — сервер журнала не запущен: предложи открыть `/mcp` и проверить
   Node.js (нужна версия 22.13 или новее).

Страница — локальный файл с выдержками из личных чатов. Не читай её в контекст, никуда не загружай и
не публикуй.
