# Подключить журнал проекта

Аргумент команды (может быть пустым): `$ARGUMENTS`

1. Папка: аргумент, если он задан; иначе — папка проекта этой сессии `${CLAUDE_PROJECT_DIR}` (если
   это выражение не заменилось путём — твоя основная рабочая папка). Относительный путь считай от
   папки проекта и передавай абсолютный.
2. Вызови инструмент `journal_connect` один раз, `cwd` = эта папка.
3. Ответь коротко: какая папка подключена (`connected`; если она выше переданной — подключён весь
   git-репозиторий); журнал собирается в фоне — прошлые чаты и git log читаются от минуты и дольше,
   готовность покажет `/agent-logbook:status`. В следующих чатах этой папки сводка журнала придёт
   при старте или агент запросит её сам.
   Если в ответе есть `profileNote`, добавь одну-две фразы о задачах проекта:
   - есть `profile.skipped` — файл `projects.json` в настройках этой машины не разобран (это не
     JSON), поэтому ничего не записано; путь к нему — в `profileNote`;
   - иначе — журнал сам нашёл папку задач (`profile.tasks.dir`, без него — `tasks`) и записал, как
     их читать, в настройки этой машины (`profile.written`); в сам проект ничего не записано. Если
     `profile.unmapped` не пуст — перечисли его: это нераспознанное, оно оставлено как есть.
   Нет `profileNote` — о задачах не говори.
4. Ошибка — передай её смысл одной фразой и остановись:
   - «Too wide for a project journal» — это корень диска или домашняя папка: попроси указать саму
     папку проекта;
   - «Not a folder» — такой папки нет: покажи, какой путь получился;
   - инструмента `journal_connect` нет — сервер журнала не запущен: предложи открыть `/mcp` и
     проверить Node.js (нужна версия 22.13 или новее).

Ничего сверх этого: не меняй настройки, не устанавливай программы, не подключай другие папки.
