# Откуда взято оформление страницы

- **Оформление.** Палитра (тёмная и светлая), устройство экранов «Центр управления» и «Вселенная» с
  орбитами — по образу веб-интерфейса raytsystem (https://github.com/romarayt/raytsystem-public-os,
  лицензия Apache-2.0, © 2026 Roma Rayt). Код интерфейса оттуда не копировался: страница написана
  заново на чистом JavaScript, без React и sigma.js, и работает без интернета.
- **Шрифты.** IBM Plex Sans, IBM Plex Mono и Bricolage Grotesque. Лицензия SIL Open Font License 1.1,
  текст — в `fonts/FONTS-OFL-1.1.txt`.
